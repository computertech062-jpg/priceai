# PriceAI — سیستەمی پێشبینیی نرخی مۆبایل بە زیرەکیی دەستکرد

**AI-Based Mobile Phone Price Prediction System**
پرۆژەی دەرچوون · بەشی زانستی کۆمپیوتەر

PriceAI وێبسایتێکە کە بە Machine Learning نرخی گونجاوی مۆبایل بە پێی تایبەتمەندییەکانی دەخەمڵێنێت،
دەڵێت ئەو نرخەی پێت وتراوە گرانە یان نا، و بە SHAP ڕوونی دەکاتەوە بۆچی.

> ⚠️ **گرنگ:** ئێستا پرۆژەکە بە **داتای نموونەیی** (`data/sample_phones.csv`) کار دەکات.
> ئەو داتایە دروستکراوە و ناو و نرخەکانی ڕاستەقینە نین. تەنها بۆ ئەوەیە سیستەمەکە کار بکات و تاقی بکرێتەوە.
> **بۆ بەحسەکەت دەبێت داتای ڕاستەقینە بەکاربهێنیت** (بڕوانە بەشی ٤). تا ئەو کاتە وێبسایتەکە ئاگادارکردنەوەیەک پیشان دەدات.

## ٢. دامەزراندن و ڕاکردن

### ڕێگای ئاسان (Windows): دوو کلیک لەسەر `run.bat`

فایلی **`run.bat`** لە فۆڵدەری `PriceAI` دا دوو کلیک بکە. هەموو شتێک خۆی دەکات:
پاکێجە پێویستەکان دادەمەزرێنێت، `.env` و `SECRET_KEY` دروست دەکات، مۆدێلەکە ڕادەهێنێت (تەنها یەکەم جار)،
سێرڤەرەکە هەڵدەکات و ماڵپەڕەکە لە وێبگەڕ دەکاتەوە. بۆ وەستاندن، پەنجەرە ڕەشەکە دابخە.

### ڕێگای دەستی

پێویستە **Python 3.10 یان نوێتر** دامەزرابێت. ئەم فەرمانانە لە ناو فۆڵدەری `PriceAI` بنووسە:

### Windows
```bat
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python -m backend.ml.train
uvicorn backend.main:app --reload
```

### macOS / Linux
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python -m backend.ml.train
uvicorn backend.main:app --reload
```

پاشان لە وێبگەڕدا بکەرەوە:
- **وێبسایت:** http://127.0.0.1:8000
- **بەڵگەنامەی API (Swagger):** http://127.0.0.1:8000/docs

**هەژماری Admin** (بە Gmail یان هەر ئیمەیڵێک):

```bash
python scripts/create_admin.py you@gmail.com
```

وشەی نهێنی دوو جار دەپرسرێت. ئەگەر ئەو ئیمەیڵە پێشتر هەژماری هەبێت، دەکرێت بە Admin و وشەی نهێنییەکەی دەگۆڕدرێت.
(ئەگەر بنکەی زانیاری بەتاڵ بێت، یەکەم کەس کە خۆی تۆمار دەکات دەبێتە Admin.)

> `python -m backend.ml.train` تەنها یەکجار پێویستە (یان هەر کاتێک داتاکە گۆڕا). نزیکەی 20 چرکە دەخایەنێت.

## ٤. بەکارهێنانی داتای ڕاستەقینە (بۆ بەحسەکە پێویستە)

1. داتایەکی مۆبایل لە **Kaggle** دابگرە. بە «GSMArena phone dataset» یان «smartphone price dataset» بگەڕێ.
   داتایەک هەڵبژێرە کە **نرخ** و **براند، مۆدێل، RAM، بیرگە، کامێرا، پاتری، شاشە، پرۆسێسەر** ی تێدابێت.
   ⚠️ داتای «Mobile Price Classification» بەکارمەهێنە، چونکە نرخی ڕاستەقینەی تێدا نییە و براند و مۆدێلیشی نییە.

2. `scripts/mapping_example.json` کۆپی بکە و لە هەر ڕیزێکدا `"from"` بگۆڕە بۆ ناوی ستوونەکە لە داتاکەتدا.

3. داتاکە بگونجێنە:
   ```bash
   python scripts/prepare_dataset.py my_kaggle_file.csv --map my_map.json
   ```
   ئەگەر نرخەکان بە دراوێکی تر بوون (بۆ نموونە ڕووپیەی هیندی)، `--rate` زیاد بکە:
   ```bash
   python scripts/prepare_dataset.py flipkart.csv --map my_map.json --rate 0.012
   ```
   ئەمە `data/phones.csv` دروست دەکات. ئاستی پرۆسێسەر (`chipset_tier`) خۆکارانە لە ناوی پرۆسێسەرەکەوە دیاری دەکرێت.

4. مۆدێلەکە دووبارە ڕابهێنە و سێرڤەرەکە ڕابکەرەوە:
   ```bash
   python -m backend.ml.train
   uvicorn backend.main:app --reload
   ```
   کاتێک `data/phones.csv` هەبێت، خۆکارانە بەکاردێت و ئاگادارکردنەوەی «داتای نموونەیی» نامێنێت.

> ئەگەر داتاکەت تایبەتمەندیی جیاوازی هەیە، تەنها `backend/ml/features.py` دەستکاری بکە.
> فۆرمی وێبسایتەکە خۆکارانە لەو فایلەوە دروست دەبێت.

### ٤-ب. نرخی بازاڕی کوردستان و عێراق (پێشنیارکراو)

داتای Kaggle نرخی کوردستانی تێدا نییە. بۆیە داتاکە دوو بەشە:

1. `data/templates/specs.csv` کۆپی بکە بۆ `data/specs.csv`. **هەر مۆدێلێک یەک ڕیز**، تایبەتمەندییە ڕاستەکان لە GSMArena یان ماڵپەڕی کۆمپانیاکە.
2. `data/templates/prices_iq.csv` کۆپی بکە بۆ `data/prices_iq.csv`. **هەر جۆرێک (RAM + بیرگە) یەک ڕیز**، نرخی نوێ لە دوکان یان ماڵپەڕێکی کوردستان/عێراق:
   ```
   brand,model,ram_gb,storage_gb,price,currency,source,date
   Apple,iPhone 15 Pro Max,8,256,1500000,IQD,ناوی دوکان,2026-11-20
   ```
   ئەگەر یەک جۆر لە چەند دوکانێک نرخی هەبێت، هەموویان بنووسە؛ میدیان وەردەگیرێت. ناوی `brand` و `model` دەبێت وەک `specs.csv` بێت.
3. دروستکردن و ڕاهێنان:
   ```bash
   python scripts/build_iq_dataset.py --iqd-rate 1450
   python -m backend.ml.train
   ```
   `--iqd-rate` نرخی دۆلاری ئەو ڕۆژەیە لە بازاڕ. سکریپتەکە هەڵەکان پیشان دەدات: ناوی هاوتا نەکراو، نرخی نائاسایی، پرۆسێسەری نەناسراو.

لە وێبسایتەکەدا، کاتێک مۆبایلێکی ناو کاتالۆگ هەڵدەبژێریت، **نرخی بازاڕ** (بە سەرچاوە و بەروار) لە تەنیشت پێشبینیی AI پیشان دەدرێت.
بۆ ئەنجامێکی باش لانیکەم 200 ڕیز (نزیکەی 80-100 مۆدێل) پێویستە. نرخەکان هەموو 1-2 مانگ جارێک نوێ بکەرەوە.

## ٥. PostgreSQL (ئارەزوومەندانە)

بە بنەڕەت SQLite بەکاردێت، کە پێویستی بە دامەزراندن نییە. بۆ PostgreSQL:

1. بنکەی زانیارییەک بە ناوی `priceai` دروست بکە.
2. `.env.example` کۆپی بکە بۆ `.env` و ئەمە بنووسە:
   ```
   DATABASE_URL=postgresql+psycopg2://postgres:YOUR_PASSWORD@localhost:5432/priceai
   SECRET_KEY=هەر-دەقێکی-درێژ-و-هەڕەمەکی
   ```
3. سێرڤەرەکە ڕابکەرەوە. خشتەکان خۆکارانە دروست دەبن.

## ٨. بۆ نووسینی بەحسەکە

- **Methodology:** `backend/ml/train.py` هەنگاو بە هەنگاو ڕوونکراوەتەوە: دابەشکردنی 80/20، log-target،
  دابەشکردن و 5-fold CV بە پێی مۆبایل (Grouped: هەموو جۆرەکانی یەک مۆبایل لە یەک بەشدان)، هەڵبژاردن بە CV (نەک Test)، Conformal Prediction، SHAP.
- **Results:** هەموو ژمارە و گرافەکان لە پەڕەی **ئەدای مۆدێل** و فایلی `backend/artifacts/metadata.json` دان.
  دوای ڕاهێنان لەسەر داتای ڕاستەقینە، ئەوانە بەکاربهێنە.
- **ڕاستگۆیی:** لەگەڵ داتای نموونەیی R² زۆر بەرزە (نزیکەی 0.95)، چونکە نرخەکان بە هاوکێشەیەک دروستکراون.
  ئەم ژمارەیە لە بەحسەکەدا بەکارمەهێنە. تەنها ئەنجامی داتای ڕاستەقینە ڕاپۆرت بکە.
- **ئاسایش:** وشەی نهێنی بە PBKDF2-SHA256 (240,000 جار) و salt ی هەڕەمەکی hash دەکرێت. JWT بۆ ناسینەوە.
- **Explainable AI:** ئەگەر `shap` دامەزرابێت، TreeExplainer یان LinearExplainer بەکاردێت.
  ئەگەرنا، Shapley values بە Permutation Sampling دەخەمڵێنرێن (`explain.py`).
